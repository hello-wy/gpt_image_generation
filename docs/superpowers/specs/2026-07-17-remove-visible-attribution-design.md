# 删除可见项目署名与入口设计

## 目标

删除应用界面中可见的 GPT Image Playground 项目链接、作者信息、赞助作者入口和指向项目 GitHub Issues 的反馈入口。

## 范围

- 删除设置弹窗的“关于”导航项及对应内容区域。
- 删除帮助弹窗中的 GitHub 项目链接和 `@CookSleep` 作者信息。
- 删除赞助提示弹窗中的邀请赞助/反馈文案、“赞助作者”入口和 GitHub“反馈问题”入口；保留“已生成超过 50 张图片”的里程碑提示和关闭功能。
- 清理因此不再使用的 `SettingsTab` 分支和图标导入。
- 保留版本检查使用的内部仓库地址，以及更新徽标指向 GitHub Release 的动态链接；这是版本更新功能的明确例外。
- 帮助弹窗仅删除页脚署名链接，其余帮助内容保持不变。不新增替代署名、赞助或反馈入口。

## 实现方式

直接删除对应 JSX，不新增替代页面、兼容分支或隐藏开关。`SettingsTab` 联合类型移除 `about`，使编译器检查残留引用。对于移除内容后为空或失去用途的容器，连同容器一起删除。

## 验证

- 先增加静态源码测试，断言 `SettingsModal.tsx` 不再包含 `about` 分支、关于页文案及其链接，`HelpModal.tsx` 不再包含页脚项目链接与作者名，`SupportPromptModal.tsx` 不再包含赞助/反馈邀请、按钮及相关链接。
- 测试同时断言 `useVersionCheck.ts` 仍保留仓库标识，`Header.tsx` 仍使用 `latestRelease.url`，明确覆盖版本更新例外。
- 运行相关测试，确认测试在实现前因现有署名内容而失败，实现后通过。
- 运行完整 `pnpm test` 和 `pnpm run build`。
